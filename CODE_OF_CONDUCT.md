# Code of Conduct

This project welcomes contributors with different backgrounds and levels of experience.
These expectations apply to issues, pull requests, reviews, and other project spaces.

## Expected behavior

- Discuss ideas and code with respect. Explain disagreements with examples and evidence.
- Help others reproduce problems and understand proposed changes.
- Accept constructive feedback and acknowledge mistakes.
- Respect other people's time, privacy, identities, and boundaries.

Harassment, threats, discriminatory language, sexualized conduct, doxxing, and
publishing private conversations or personal information without consent are not acceptable.

## Reporting and moderation

For abuse or threats, use [GitHub's private reporting channel](https://support.github.com/contact/report-abuse).
Include links to the relevant project interactions. Do not repeat private information
in a public issue. For other moderation concerns, contact [@minkinad](https://github.com/minkinad)
to arrange a private channel before sharing sensitive details.

The maintainer may edit or remove harmful content, lock conversations, limit
participation, or block accounts. Responses should reflect the severity, impact,
and repetition of the behavior. An affected participant may request a review of
a moderation decision through the same reporting channel.

The maintainer follows these standards as well. GitHub's reporting process remains
available if the concern involves the maintainer.
